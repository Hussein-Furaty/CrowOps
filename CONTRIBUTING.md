# Contributing to CrowOps

Thank you for your interest in contributing to CrowOps.

## How to Contribute

- Report bugs by opening an issue.
- Suggest new features through GitHub Discussions or Issues.
- Fork the repository and create a feature branch.
- Keep pull requests focused on a single change.
- Follow the project's coding standards.
- Update documentation when necessary.

## Branch Naming

Examples:

- feature/server-management
- feature/docker-monitoring
- bugfix/ssh-timeout
- docs/readme-update

## Commit Messages

Examples:

- feat: add server entity
- fix: resolve SSH connection timeout
- docs: update installation guide
- refactor: improve service structure

## Pull Requests

Before submitting a pull request:

- Ensure the project builds successfully.
- Write clear commit messages.
- Keep changes small and focused.
- Update documentation if applicable.

Thank you for helping improve CrowOps.
